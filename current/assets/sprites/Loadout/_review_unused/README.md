# Unused Loadout artwork review

This directory preserves superseded or currently unreferenced PNGs for manual review.
It is not a runtime asset source: active Loadout artwork must be referenced by the
Loadout catalog or by `src/config/coopDefenseUpgradeIcons.json`, and the upgrade-icon
audit intentionally ignores this directory.

Move an image back to the parent directory only together with an explicit active
runtime reference.
