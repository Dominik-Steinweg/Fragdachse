# Bodenvarianten – Auswahlserie 02

12 separat mit dem eingebauten Imagegen-Werkzeug erzeugte Quellen: sechs Gras-, sechs Erdvarianten.
Farb- und Materialreferenz ist das zweite Vergleichsbild des Nutzers.

[Beschriftete Galerie](index.html) · [Exakte Prompts](prompts.json)

Die PNGs sind unveränderte Generierungsergebnisse. Noch keine Auswahl, Aufbereitung oder Integration
in die Produktionsassets. Auf Nutzerwunsch keine Detail-, Kachel-, Browser- oder Spielprüfung.

Geplante physische Abbildung: jede Quelle stellt 8 × 8 Meter dar; bei 32 Weltpixeln pro Meter
entspricht das später 256 × 256 Weltpixeln. Die Quellauflösung ist keine Darstellungsgröße.
