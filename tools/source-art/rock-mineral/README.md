# Mineral coverage

`coverage.png` is the canonical 2176×1870 silhouette: every alpha byte equals the accepted canonical silhouette; RGB is white and has no material meaning. `scripts/export-slate-v7.mjs` uses it for both 1× and 2× exports and copies it to the CPU-only runtime coverage PNG. Geometry source hashes normalize CRLF to LF; binary source/output hashes do not normalize.
