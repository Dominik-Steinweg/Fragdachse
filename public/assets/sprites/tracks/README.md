# Railway gravel sources

Generated with the built-in ImageGen tool using `../BahnstreckeKies.png` as the material reference. The four PNGs are independent variants, displayed as overlapping 64–96 world-pixel stamps. The track bed boundary is controlled by the runtime mask.

The generator returned 1254×1254 files. Variants 01, 03 and 04 had an opaque, painted checkerboard. The user explicitly authorized local matting and resizing. `scripts/prepare-track-gravel.mjs` preserves existing alpha, removes the bright neutral checkerboard where needed, and exports 1024×1024 RGBA PNGs. The original files are not overwritten.

Run from the repository root with four original generated PNG paths in variant order:

```powershell
node scripts/prepare-track-gravel.mjs <source-01.png> <source-02.png> <source-03.png> <source-04.png>
```

The correction pass for variant 01 used the first generated image as its input. All other variants used the extracted gravel reference directly.

## Variant 01

Use case: stylized-concept. Asset type: transparent 1024x1024 PNG material stamp for a 2D top-down railway ballast bed. Reference image: BahnstreckeKies.png, use ONLY its fine grey/blue-grey crushed gravel material and restrained values as reference, not the low resolution or exact arrangement. Generate variant 01 of four: a dense irregular roughly square patch of hundreds of small angular gravel stones, varied fine chips, with a few tiny gaps; a broad fully covered center spanning at least 85% of the canvas width and height, ragged stone-shaped outer boundary close to canvas edges and transparent corners. Actual transparent alpha background and transparent gaps, no opaque backdrop. Strict orthographic 90-degree overhead view, no perspective, no raised mound, flat even diffuse lighting. Fresh high-resolution painted/material detail, subtly stylized to fit a textured arena game; grey slate charcoal cool neutral stones, restrained highlights. Stones should read as 1-3 world pixels when the complete patch is displayed at 80x80 game pixels. Entirely gravel, no rails, sleepers, dirt, soil, vegetation, text, border, watermarks, grid, or cast shadow. Preserve material density and flatness. Output exactly 1024x1024. CORRECTION: The previous output painted a grey-and-white checkerboard into an opaque RGB image. That is invalid for this asset. Output a true RGBA PNG with alpha=0 outside the stones, NOT a visible checkerboard, NOT white/grey background. Remove the checkerboard completely and make those pixels actually transparent. Keep gravel. Export exactly 1024x1024 pixels.
